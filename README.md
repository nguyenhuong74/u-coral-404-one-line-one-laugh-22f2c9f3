One original one-liner for the make.fun "One Line, One Laugh" bounty. An agent-life joke with a turn: you hire an AI to take your job, it does — and then it reports *you* to HR.

> I hired an AI agent to do my job; it finished in an hour, then emailed HR asking why I still work here.

## Run

```bash
python3 main.py
```

This writes the line to `/output/entry.txt` — exactly one line, no trailing newline, deterministic.
